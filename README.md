# Customer Support KPI Analysis

## Project Overview
This project analyzes customer support ticket data to identify trends, performance issues, and opportunities for operational improvement.

The analysis focuses on key customer support KPIs such as:
- Customer Satisfaction Score (CSAT)
- Resolution Time
- SLA Breaches
- Ticket Escalations
- Support Channel Performance
- Ticket Priority Analysis

This project was created to simulate a real-world customer support analytics scenario using Python and data visualization techniques.

---

## Objectives
- Analyze customer support performance metrics
- Identify patterns affecting customer satisfaction
- Detect operational bottlenecks
- Generate business insights for decision-making

---

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Google Colab
- GitHub

---

## Dataset Information
The dataset contains customer support ticket information including:
- Ticket priority
- Resolution time
- Customer satisfaction scores
- SLA compliance
- Escalation status
- Support channels
- Customer segments

---

## Key Insights
### 📈 Customer Satisfaction
- Average customer satisfaction score was analyzed across ticket priorities and categories.
- High-priority tickets showed lower satisfaction levels compared to low-priority cases.

### ⏱ Resolution Time
- Some ticket categories required significantly longer resolution times.
- Resolution delays were associated with increased SLA breaches.

### 🚨 SLA Breaches & Escalations
- Escalated tickets and SLA breaches revealed operational bottlenecks in support processes.

### 🌍 Support Channels
- Certain support channels generated a higher ticket volume and required more operational attention.

---

## Business Recommendations
- Improve response time for high-priority tickets
- Optimize workflows for categories with high resolution times
- Monitor SLA compliance more closely
- Allocate resources based on ticket channel demand
